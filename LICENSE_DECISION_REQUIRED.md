# Software licence decision required

No software licence has been assigned to this pre-release package because the
authors and their institutions have not yet confirmed the intended reuse terms.
Until a licence is selected, copyright law reserves reuse rights by default.

Before minting a public release DOI, the authors should select an institutionally
approved software licence, add the corresponding `LICENSE` file, record the
licence in the repository settings and archive metadata, and regenerate the
public-release integrity manifest from the tagged commit.

Third-party Endomondo/FitRec and GoldenCheetah records are not redistributed and
are not relicensed by this repository.
